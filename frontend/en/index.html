JPN-PBM — Programmable Subsidy Infrastructure

Open-source reference implementation of Purpose-Bound Money (PBM) for the Tokyo Metropolitan Government. Yen-denominated subsidies issued by the city carry machine-readable purpose constraints, redeemed at neighborhood retailers via ordinary point-of-sale, settled in JPYC stablecoin. ★ World-first disaster-resilient offline redemption (CP-6)

Why this matters

Purpose-bound
Programmable yen
JPYC locked as collateral; unlocked only for eligible JAN × approved store × valid resident.
MyNumber link
Privacy-preserving
Address (ward) / age / sex used for eligibility; the My Number itself is HMAC-pseudonymized.
JAN-level control
Per-product policy
Per-program eligible-JAN list; non-eligible items receive zero subsidy.
EBPM
k-anonymous KPIs
Cells with fewer than 5 citizens are suppressed; policy effect visible in real time.

Open source & reproducible

Apache 2.0 licensed. CI runs verify.sh all (pytest + seed + sol + front + audit + i18n) on every PR. Reproduce locally: 

git clone https://github.com/kota1026/JPN_PBM
cd JPN_PBM
pip install -r backend/requirements.txt
bash scripts/verify.sh all
( cd backend && uvicorn app.main:app --reload )
# open http://127.0.0.1:8000/
