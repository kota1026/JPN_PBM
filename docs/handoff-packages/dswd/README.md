## Why this benefits DSWD

- **Reduces 4Ps leakage**: in cash-based 4Ps, an estimated 5–8% leaks to alcohol/tobacco/non-essential. PBM enforces this on-chain, blocking MCC 5921/5993/5813.
- **Disaster resilience**: typhoon-induced network outage no longer halts 4Ps disbursement (CP-6).
- **Real-time KPI dashboard for management**: utilization, leverage, k-anonymous demographics — accessible to DSWD without raw PII access.
- **Open-source: no vendor lock-in**, full DSWD ownership of the deployment.
