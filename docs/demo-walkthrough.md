### Scene 6: on-chain spend → JPYC 即時清算 (22 秒)

**画面表示**:
```
┌─ チェーン上の 5 段検証 ─────────────────────────┐
│ ┌citizen ┐┌store  ┐┌JAN    ┐┌period ┐┌cap    ┐│
│ │ ✓     ││ ✓     ││ ✓     ││ ✓     ││ ✓     ││
│ └───────┘└───────┘└───────┘└───────┘└───────┘│
│                                                │
│         ┌── spend() ──┐ ⚡                    │
│         │ JPYC 転送   │                       │
│         └─────────────┘                       │
└────────────────────────────────────────────────┘

┌─ EBPM ダッシュボード (k-匿名集計) ─────────────┐
│ 本日の利用       : 342 件                     │
│ 補助総額        : ¥2.84M                     │
│ CP-2 ブロック試行 : 7 件 (赤)                 │
│ k-匿名性        : k=5 強制                   │
└───────────────────────────────────────────────┘
```

**ナレーション (JP)**:
> spend() トランザクションは 5 つの require を通過し、補助分の JPYC が トレジャリーから加盟店に即時転送されます。Spent イベントが emit され、EBPM ダッシュボードがリアルタイム更新。k=5 を機械的に強制するので、個人特定は構造的に不可能です。

### Scene 8: ★ ネット遮断中の POS ローカル検証 (22 秒)

**画面表示**:
```
┌─ ⚠ ネット切断中 ──────────────────────────────┐
│ QR スキャン受領                          ✓     │
│ 公開鍵で署名検証 (オフライン)              ✓     │
│ cap ¥10,000 残量チェック              ✓ ¥7,400残│
│ 期限内 (+30 day grace)                  ✓     │
│                                                │
│ ┌─────────────────────────────────────┐ ⚡   │
│ │ 🍙 米 5kg + 水 6L 受給 → 紙レシート発行 │       │
│ └─────────────────────────────────────┘       │
└────────────────────────────────────────────────┘
```

**ナレーション (JP)**:
> 災害時、加盟店 POS は QR を読み取り、キャッシュ済の governor 公開鍵でローカル署名検証 + nonce 重複チェック + cap 残量確認を行います。すべてオフラインで完結。住民は その場で物資を受け取り、紙のレシートも併発行されます。世界中で、能登半島地震を経験した国でこの仕組みを持つ自治体はありません。

### Scene 9: ★ 復旧後 batch 精算 (18 秒)

**画面表示**:
```
┌─ PBMOfflineFallback.redeemBatch(items[]) ─────┐
│ require(approvedStores[msg.sender]);   ✓      │
│ for (item in items):                          │
│   require(ecrecover(digest, sig) == gov);  ✓  │
│   require(consumed[pid][month]+amt <= cap);✓  │
│   consumed[pid][month] += amount;             │
│   jpyc.transfer(msg.sender, amount);     ⚡   │
│   emit Redeemed(programId, pid, store, ...);  │
│                                               │
│ 合計精算: ¥1.34M (143 redemptions)            │
└───────────────────────────────────────────────┘
```

**ナレーション (JP)**:
> ネット復旧後、POS が蓄積していた redemption batch を on-chain に提出。contract が再検証 (署名 + nonce + cap) を行い、JPYC を加盟店に送ります。consumed mapping で二重支給は構造的にゼロ。30 日 grace 期間つきで、複数回の災害でも対応可能。

## 🎮 プレイヤー UI

`demo.html` 上下のフレーム:

```
┌─ 🟢🟢🟢🟡⚪⚪⚪⚪⚪⚪⚪⚪⚪  ▶ 自動再生中: 第1幕 Tokyo Citizen   1:04 / 5:00 [日本語|English|Tagalog]┐
```

操作:
- **自動進行** ─ 各シーン duration 秒で次へ
- **言語切替** ─ 右上の `日本語/English/Tagalog` ボタンで全テキスト即時切替
- **一時停止** ─ ⏸ で停止、再開も同ボタン
- **前後** ─ ⏮/⏭ でシーン単位ジャンプ
- **リスタート** ─ ⟲ で先頭へ
- **Hash deep-link** ─ `/ui/demo.html#scene-7` で CP-6 シーンへ直接

## 🚀 実機で見る最短手順

```bash
# ターミナル 1
cd /home/user/JPN_PBM/backend
uvicorn app.main:app --reload

# ターミナル 2 (ブラウザ起動可能なら)
xdg-open http://127.0.0.1:8000/ui/demo.html   # Linux
open http://127.0.0.1:8000/ui/demo.html        # macOS
start http://127.0.0.1:8000/ui/demo.html       # Windows
```

または、stop 後に `bash scripts/build_handoff_package.sh jica` を実行すると、handoff zip にも `frontend/demo.html` を含めて 1 ファイルで送付可能 (R18 で対応予定)。
